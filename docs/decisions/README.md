## DEC-v3-002 结构描述子 train-serve 矛盾

- 来源：v2.1 L1-SHAP 实测（Top 特征几乎全为结构描述子）+ 用户本轮「改 API 输入」决策。
- 决策：保留结构描述子入模，API/生成器支持传入 8 个真实结构描述子；缺省用训练均值填充，
  返回 `structure_source` 提示可信度；不新增「仅组分」对照模型（避免过度扩展）。
- 备选（未采纳）：改为仅用组分可得特征训练（会丢弃 8 个高 SHAP 贡献特征，指标大幅下降）。
- 状态变更：推理结构特征「固定 0.01」→「可传真值 + 均值兜底 + 来源标记」。
- 待确认：普通用户无 DFT 结构值时的体验（当前以均值填充并标注提示）。
