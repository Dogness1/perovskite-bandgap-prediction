## 2. 内部不自洽（provenance: 指标对账_v3.0 §1.2 + 本机实测）

281 配对样本 HSE 带隙标准差 **std = 1.4746 eV**（本机实测，见 `指标对账_v3.0.md` 附录）。
由 R² = 1 − RMSE²/std²，正态误差下 MAE ≈ 0.7979·RMSE：

- 若 MAE ≈ 0.12 eV → RMSE ≈ 0.150 eV → R² ≈ **0.9896**
- 若 R² ≈ 0.92 → RMSE ≈ 0.417 eV → MAE ≈ **0.333 eV**

因此「MAE 0.10–0.14 且 R² 0.90–0.94」在同一 std=1.4746 eV 的目标分布上**数学上不能同时成立**。
文献侧佐证：Feng & Wang 2024（Molecules 29(2):499, PMID 38276577）报 MAE 0.0901 对应 R² 0.9913，
而非 0.92——即低 MAE 配的是高 R²，与导师区间表的组合方式不符。
（provenance: 优化方案_v2.0 附录B[2]、指标对账_v3.0 §1.2）

## 2.5 口径对标（关键澄清）

导师文档3的验收区间历史上是按 **oracle_pbe（PBE_true + Δ_pred，场景A）** 报告的，
不是 end_to_end（PBE_pred + Δ_pred，场景B）。证据：
- 指标对账_v3.0 §1「C1 随机 CV 0.9398 落在 0.90–0.94 上沿」——0.9398 正是 oracle 口径；
- v2.0 CHANGELOG「此前报告的数字都属于场景 A（PBE 用测试折真值加回）」；
- Web API 运行在 end_to_end，其 R² 约 0.748，若拿导师 R²0.90–0.94 判定会全面不达标——这是口径错配。

因此本版验收判定对 **oracle_pbe** 执行；end_to_end 作为部署口径单独报告，不拿导师区间判定。
两个口径不可混用（宪法 5.3）。

## 3. 本轮决策：以 R² 为准，MAE 上修（DEC-v3-001）

用户本轮拍板：**R² 区间不变，MAE 按目标方差重新推导**。上修后的自洽验收线：

| 验证方式 | R²（沿用导师） | MAE（上修，正态误差反推） |
|---|---|---|
| 随机 10×5 CV | 0.90–0.94 | **0.29–0.37 eV** |
| GroupKFold | 0.75–0.85 | **0.47–0.60 eV** |
| 独立外部集 | 0.70–0.82 | **0.52–0.66 eV** |

推导：MAE = 0.7979 × std × √(1−R²)，std = 1.4746 eV。
随机 CV：R²0.90→MAE0.372，R²0.94→MAE0.288，取 0.29–0.37。
GroupKFold：R²0.75→MAE0.600，R²0.85→MAE0.468，取 0.47–0.60。
外部集：R²0.70→MAE0.660，R²0.82→MAE0.519，取 0.52–0.66。

## 4. 达标判定方式

对每个验证口径分别判定 R² 与 MAE 是否落入上修区间，给出分层结论：
- **R² 达标 + MAE 达标** → 全面达标
- R² 达标、MAE 优于区间下界（更小）→ 达标（MAE 越小越好）
- 任一项不达标 → 如实报告差距，不修改数字凑区间（宪法 7）

## 5. 已知不可由代码解决的缺口

- 独立外部测试集：当前 `group_disjoint` 用 group-disjoint 划组（K_Ca 22 样本），
  非真正独立数据源；按导师规则不可作论文最终泛化主结论（provenance: 指标对账_v3.0 §P0-2）。
- Δ 模型可学性：R²_Δ 仅 0.397（指标对账_v3.0 §1.3），MAE 进一步下探需新描述子或 DFT 补样，
  属 P1 高成本路径，本版不承诺（provenance: 同上）。
